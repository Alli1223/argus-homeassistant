# Changelog

## 0.12.0

- Runs the Argus 0.12.0 agent.
- Reads UPSes from Network UPS Tools: the Network UPS Tools add-on by default, or the server set in
  the new **UPS server** option.
- New **Allow power actions** option, which lets Argus shut the machine down and restart it.
